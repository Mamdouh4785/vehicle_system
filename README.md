# نظام إدارة المركبات

تطبيق إدارة أسطول ومتابعة صيانة مبني بـ PHP وMySQL، ويعمل محليًا عبر XAMPP.

## تنظيم المشروع

- صفحات PHP في الجذر: نقاط الدخول والواجهات ومعالجات النماذج. بقيت في مواقعها للحفاظ على الروابط الحالية.
- `config.php` و`functions.php`: اتصال قاعدة البيانات والدوال المشتركة.
- `assets/css/` و`assets/js/`: ملفات الواجهة الثابتة.
- `assets/images/catalog/`: صور ثابتة وملفات صور أصلية غير مرتبطة برفع المستخدمين.
- `images/`: صور المركبات التي يعرضها التطبيق ويستقبلها من النماذج.
- `uploads/`: صور المستخدمين وتقارير المركبات المرفوعة.
- `tests/`: اختبارات PHPUnit.
- `vendor/`: اعتماديات Composer المثبتة.

اعتماديات PHP مسجلة في `composer.json` و`composer.lock`، وملفاتها المثبتة داخل `vendor/`.
